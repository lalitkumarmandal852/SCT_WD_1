# SCT_WD_1 - Landing Page

## 📌 Task Overview
This is **Task 1** of my Web Development Internship at **SkillCraft Technology**. The project is a simple, responsive landing page built using pure **HTML and CSS**.

## 🚀 Features
- Fixed navigation bar with smooth scrolling
- Multiple sections: About, Home, Projects, Services, Contact
- Hover effects on navigation links
- Clean, minimal single-page layout
- Section-based color theming for visual separation

## 🛠️ Tech Stack
- **HTML5** - Page structure
- **CSS3** - Styling, layout, and hover interactions
